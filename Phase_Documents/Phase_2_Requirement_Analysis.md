# Phase 2: Requirement Analysis

## Software Requirements
- **Operating System:** Windows 10/11, macOS, or Linux (cross-platform operations).
- **Node.js (v16 or above):** Runtime ecosystem running server logic.
- **npm (v8 or above):** Node package manager.
- **Express.js:** Lightweight routing web framework.
- **MongoDB:** Document NoSQL engine for storing users, materials, and resources.
- **Postman:** API verification toolkit.
- **Code Editor:** Visual Studio Code.

## Hardware Requirements
- **Processor:** Intel Core i5 (8th Gen or above) / AMD Ryzen 5 or equivalent.
- **RAM:** 8 GB minimum (16 GB recommended).
- **Storage:** 1 GB of available disk workspace.

## Functional Requirements
- **Authentication:** JWT-based login and registration with bcrypt password hashing.
- **Material Management:** Upload .txt, .md, .pdf files for AI processing.
- **AI Integration:** Integration with Google Gemini API to generate summaries, flashcards, quizzes, and study plans.
