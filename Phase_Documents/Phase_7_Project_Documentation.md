# Phase 7: Project Documentation

## Included Documentation

The following documents have been completed and are included in the repository:
1. **API Documentation:** `API_DOCUMENTATION.md` provides detailed endpoints, curl commands, and expected JSON responses for every API route.
2. **Project Report:** `_AI StudyBuddy.docx.pdf` serves as the detailed project report, covering the problem statement, architecture, setup guide, and testing screenshots.
3. **Phase Documents:** This `Phase_Documents` directory organizes the software development life cycle (SDLC) artifacts as per the project requirements.

## How to Run the Project
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Create a `.env` file with `MONGO_URI`, `JWT_ACCESS_SECRET`, and `GEMINI_API_KEY`.
4. Run `npm start` to start the Nodemon development server.
